Toutes les Fonctionnalites

Automation Factory est un constructeur visuel de playbooks Ansible pour les equipes DevOps. Voici tout ce qu'il sait faire.

Version actuelle : v2.3.6 — 14 mars 2026

UI
Interface & Editeur Visuel
Construction et navigation dans vos playbooks

Drag & Drop intuitif

v1.0+

Glissez-deposez modules, blocs et roles pour construire vos playbooks visuellement. Reordonnez les taches en quelques clics.

  • 5 zones de travail : pre_tasks, tasks, post_tasks, handlers, roles
  • Blocs imbriques avec rescue/always
  • Liens visuels entre taches

Preview YAML en temps reel

v1.0+

Visualisez le YAML genere en temps reel pendant que vous construisez votre playbook visuellement. Zero surprises a l'execution.

Theme clair / sombre

v2.2.1

Trois modes : Clair, Sombre et Systeme (suit la preference du systeme d'exploitation). La page de login est toujours en mode clair.

Validation Ansible-lint

v1.12+

Validation en temps reel avec ansible-lint integre. Corrigez les erreurs avant meme d'executer votre playbook.

  • Severite : erreur, avertissement, info
  • IDs de regles Ansible-lint
  • Numeros de lignes precis

Variables typees

v1.15+

Definissez le type (string, int, bool, list, dict), le caractere obligatoire/optionnel et la valeur par defaut de chaque variable.

Assertions automatiques

v1.17+

Generation automatique de blocs d'assertions pour valider les variables d'entree. Un bloc par variable, visible mais verrouillee.

IO
Import & Export
Migrez vos playbooks existants, exportez dans tous les formats

Import YAML Ansible

Nouveau v2.3.6

Importez directement vos fichiers .yml/.yaml existants dans l'editeur visuel. Le parseur resout automatiquement include_tasks, import_tasks, vars_files et import_playbook.

  • Support .yml et .yaml
  • Resolution des includes et imports
  • Chargement group_vars / host_vars

Import archives ZIP

Nouveau v2.3.6

Importez une archive ZIP contenant un role Ansible complet. L'outil decouvre automatiquement les playbooks, les roles, les group_vars et host_vars.

  • Decouverte automatique de la structure
  • Parsing des roles en playbooks synthetiques
  • Dialog multi-etapes avec feedback

Export JSON (.abd)

v2.1+

Sauvegardez votre diagramme complet avec positions des blocs, etat de l'interface et metadonnees. Versionnage et verification d'integrite integres.

Export Mermaid (.md)

v2.1+

Generez un diagramme Mermaid de votre playbook, directement integrable dans votre documentation GitHub, GitLab ou Confluence.

Export SVG

v2.1+

Exportez votre diagramme en image vectorielle SVG, ideale pour les presentations et la documentation technique.

Export YAML

v1.0+

Generez le YAML Ansible propre et valide, pret a etre execute. Les roles desactives sont exclus, les variables correctement serialisees.

G
Integrations Galaxy & Ansible
Acces a l'ecosysteme Ansible complet

36 000+ roles Galaxy

v2.0+

Acces direct aux roles Ansible Galaxy via les API v1 (roles standalone) et v3 (roles de collections). Drag & drop vers votre playbook.

  • API v1 pour les roles legacy (auteur.role)
  • API v3 pour les roles de collections
  • Cache 30 minutes pour les listes

Galaxy prive (AAP / Galaxy NG)

v2.0+

Connectez votre instance Ansible Automation Platform ou Galaxy NG privee. Bascule entre Galaxy public et prive en un clic.

Administration des sources Galaxy

v2.3+

Interface d'administration pour gerer les sources Galaxy. Activation/desactivation du Galaxy public, multi-sources privees avec priorite par drag & drop.

  • Chiffrement Fernet AES pour les tokens
  • Test de connexion en temps reel
  • Rechargement a chaud de la configuration

Documentation Ansible integree

v1.10+

Detection dynamique de la version Ansible depuis la documentation officielle. Acces direct aux parametres de chaque module avec tooltips.

  • 70+ collections par version Ansible
  • Cache 24h pour les versions
  • Fallback hors-ligne

Vue arborescente (TreeView)

v1.14+

Navigation hierarchique namespace / collection / module avec chargement paresseux. Drag & drop direct depuis la TreeView vers le playbook.

CO
Collaboration Temps Reel
Travaillez ensemble sur vos playbooks, simultanement

Edition collaborative WebSocket

v1.13+

Plusieurs utilisateurs editent le meme playbook simultanement. Les modifications de chacun s'affichent en temps reel sur tous les ecrans.

  • Roles : Proprietaire, Editeur, Visualiseur
  • Partage par nom d'utilisateur
  • Avatars des utilisateurs connectes

Sync variables en temps reel

Ameliore v2.3.6

Les ajouts, modifications et suppressions de variables se synchronisent maintenant correctement chez tous les collaborateurs en temps reel.

Sync roles en temps reel

Ameliore v2.3.6

Les ajouts de roles, suppressions, reordonnancement et bascules actif/inactif se propagent instantanement a tous les collaborateurs.

Gestion des conflits

v1.14+

Versionnage des playbooks pour la detection de conflits d'edition. Updates granulaires (module, config, liens, plays) avec debounce 300ms.

Audit log

v1.13+

Toutes les modifications collaboratives sont enregistrees avec horodatage et identite de l'auteur. Transfert de propriete automatique a la suppression.

S
Securite & Acces
Controle d'acces et protection des donnees

Authentification JWT

v1.0+

Authentification securisee par tokens JWT. Session automatiquement renouvelee, isolation complete entre utilisateurs.

Acces admin protege

v1.8+

Interface d'administration reservee aux administrateurs. Gestion des namespaces standards, sources Galaxy, types de variables personnalises.

Chiffrement des tokens Galaxy

v2.3+

Les tokens d'acces aux instances Galaxy privees sont chiffres en base de donnees avec Fernet (AES 128-bit). Jamais stockes en clair.

Multi-tenant

v1.0+

Toutes les donnees utilisateur (playbooks, variables, favoris, types) sont strictement isolees par utilisateur. Architecture scalable horizontalement.
